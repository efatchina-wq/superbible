# Assets - SuperQuizz Biblique

Ce dossier contient les ressources graphiques, animations et médias de l'application :

## Structure recommandée :
- `/assets/images/` : Illustrations des thèmes bibliques, bannières, avatars.
- `/assets/icons/` : Icônes de l'application (`icon.png`, `adaptive-icon.png`, `favicon.png`).
- `/assets/animations/` : Fichiers d'animations Lottie pour les récompenses de victoire (`confetti.json`, `levelup.json`).
- `/assets/sounds/` : Effets sonores optionnels (`correct.mp3`, `incorrect.mp3`, `victory.mp3`).

## Tailles Expo recommandées :
- `icon.png` : 1024 x 1024 px
- `splash.png` : 1284 x 2778 px (ou 2048 x 2048 px centré)
- `adaptive-icon.png` (Android) : 1024 x 1024 px
